# text to calendar

選択したテキストをGoogleカレンダーの予定として簡単に追加できるChrome拡張機能です。

## 機能

- 2クリックで選択したテキストをカレンダー予定として追加
- ブラウザ上の任意のテキスト選択に対応
- 選択したテキストを予定のタイトルとして設定し、Googleカレンダーを新規タブで開く

## インストール方法

1. このリポジトリをダウンロードまたはクローン
2. Chromeで `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、拡張機能のファイルが含まれるディレクトリを選択

## 使い方

1. ウェブページ上の任意のテキストを選択
2. 選択したテキストを右クリック
3. コンテキストメニューから「カレンダーに予定を追加」をクリック
4. 新規タブでGoogleカレンダーの予定作成画面が開き、選択したテキストが予定のタイトルとして設定される

## 技術的な詳細

- Chrome拡張機能 Manifest V3 で構築
- ChromeのContext Menus APIを使用
- 認証不要
- 軽量で高速

## ファイル構成

- `manifest.json`: 拡張機能の設定ファイル
- `background.js`: コンテキストメニューとカレンダー連携を処理するサービスワーカー

## 開発方法

拡張機能を修正する場合：

1. ソースファイルを編集
2. `chrome://extensions/` を開く
3. 拡張機能カードの更新アイコンをクリック
4. 変更をテスト
